# Pen Fight

**A physics-based pen-flicking game set on a classroom desk.** Aim your shot, flick your pen, and try to be the last one still on the desk.

<p align="center">
  <a href="https://hermedev.github.io/Pen-Fight-Play/"><strong>▶ Play Pen Fight</strong></a>
</p>

## How to play

- Choose a match with 2–4 pens. Play solo against bots or take turns locally with other players.
- On your turn, press your pen and drag away from it to aim and set the shot strength.
- Release to flick. Use collisions to push rival pens off the desk while keeping yours in play.
- The last pen on the desk wins.

## Controls and screens

- **Touchscreen:** drag back from your pen and release to shoot.
- **Mouse:** click and drag back from your pen, then release.
- **Phones and tablets:** landscape is recommended for gameplay. Rotate your device if the portrait orientation prompt appears.
- **Desktop:** use the game page’s fullscreen control for a larger view.

Fullscreen availability depends on the browser and device. Some mobile browsers require a tap on the fullscreen button or opening the game from the home screen.

## About this repository

This repository contains the published Unity WebGL build for GitHub Pages. The game is built with Brotli-compressed data, framework, and WebAssembly files in `Build/`, along with the Unity loader and page assets. Keep `index.html`, `Build/`, and `TemplateData/` together when deploying; the page references those paths directly.

The public game is available at **[hermedev.github.io/Pen-Fight-Play](https://hermedev.github.io/Pen-Fight-Play/)**.
